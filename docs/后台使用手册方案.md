# 后台「使用手册」方案

> 目标：把操作手册做进后台，操作人员随用随查；手册正文可编辑，改版后**不用改代码**即可同步更新。

## 一、选型结论

考虑过三种做法：

| 方案 | 做法 | 问题 |
| --- | --- | --- |
| A 静态页 | 把手册 HTML 放进 `admin/`，侧栏加链接 | 每次改界面都要手改 HTML，容易和系统脱节 |
| **B 正文入库可编辑** ✅ | 章节正文存库，后台自带富文本编辑器 + 截图上传 | 无（本方案） |
| C 外链文档 | 链到腾讯文档 / 在线帮助站 | 与后台割裂，权限和外网访问另说 |

选 **B**：章节拆到「节」粒度入库，后台页面既当阅读器又当编辑器，改文案、换截图都在后台完成。

## 二、数据模型

表 `manual_sections`（建表脚本 `backend/scripts/create-manual-sections-table.js`）：

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PK | 自增 |
| `section_key` | TEXT UNIQUE | 稳定键，如 `c5-1`，用于迁移与去重 |
| `chapter_no` | TEXT | 章号 `5`，排序用 |
| `chapter` | TEXT | 章标题 `配方管理` |
| `title` | TEXT | 节标题 `5.1 配方列表`；独节章直接用章名 |
| `body_html` | TEXT | 正文 HTML（含 `<figure>` 截图与标注） |
| `sort_order` | INTEGER | 章内排序，索引 `idx_ms_sort` |
| `is_published` | INTEGER | 是否展示 |
| `updated_by` | TEXT | 最后修改人邮箱 |
| `created_at` / `updated_at` | DATETIME | 时间戳 |

Prisma 模型同名 `ManualSection`，已写入 `backend/prisma/schema.prisma`。
**注意**：表建在数据文件（`backend/prisma/gattefosse.db`）里，**不随 deploy 走**，部署后必须到线上补跑 `--apply`。

## 三、接口

`backend/src/routes/manual.routes.ts`，挂在 `/api/manual`：

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/sections` | 登录即可 | 按章分组返回 `{ total, chapters:[{no,title,sections:[...]}] }` |
| POST | `/admin/sections` | editor / super_admin | 新建节，`section_key` 重复返回 409 |
| PUT | `/admin/sections/:id` | editor / super_admin | 保存正文，自动记 `updated_by` |
| DELETE | `/admin/sections/:id` | editor / super_admin | 删除节 |
| POST | `/admin/sections/reorder` | editor / super_admin | 章节重排 |
| POST | `/admin/upload` | editor / super_admin | 上传截图 → `uploads/manual/`，只收图片、不生成缩略图 |

## 四、后台页面

`admin/manual-standalone.html`（iframe 子页，与「作者管理 / 系统设置」同一套架构）：

- 左侧：章分组目录 + 搜索框；右侧：正文。
- 阅读态 / 编辑态切换；编辑态用 `contenteditable` + 富文本工具栏：
  `B / I / H / ¶ 正文 / • 列表 / 1. 列表 / ①② 步骤 / 💡 小贴士 / ⚠️ 注意 / ― / 🖼 插入截图 / ▢ 加标注框 / 清空标注 / 改图注 / 源码`。
- 截图标注：在图片上拖框加红框 + 序号圆点（百分比定位），旧标注进编辑态时自动统一编号。
- 入口两处：侧栏「帮助 → 使用手册」，以及顶栏右侧 `?` 按钮。

接入主页面需改 4 处（`admin/index.html`）：侧栏 `nav-item`、iframe 的 `v-if`、`iframeUrl()` 映射、`breadcrumbText()`。

> ⚠️ 子页引用的是 `vue.global.prod.js`，它**不暴露全局 `createApp`**，必须写 `const { createApp } = Vue;`。

## 五、初始内容迁移

`backend/scripts/import-manual-sections.js`：

1. 复制 `docs/manual/assets/raw/*` → `backend/uploads/manual/`；
2. 按 `<h2 id="cN">` / `<h3 id="cN-M">` 切章分节，章号 `c5-1` → `5.1`；
3. 正文图片路径 `assets/raw/` → `/uploads/manual/`；
4. 写库；**已存在的 `section_key` 默认跳过**（保护后台的编辑成果），要覆盖加 `--force`。

首次执行结果：导入 **23 节 / 11 章**（章 0~10），复制截图 32 张。

## 六、部署

```bash
# 1) 代码
git push origin main
# 2) release 分支（本项目固定流程）
git commit-tree main^{tree} -p refs/heads/release -m "release: ..."
git update-ref refs/heads/release <新 hash>
git push deploy release:master

# 3) 线上补建表 + 导入（表不随 deploy 走）
ssh gattefosse "cd /opt/gattefosse/backend && node scripts/create-manual-sections-table.js --apply"
ssh gattefosse "cd /opt/gattefosse/backend && node scripts/import-manual-sections.js --apply"

# 4) 实测
curl -s http://127.0.0.1:3000/api/manual/sections -H "Authorization: Bearer <token>"
```

## 七、怎么跟着系统改版更新

| 场景 | 操作 |
| --- | --- |
| 界面文案/步骤变了 | 后台「使用手册」→ 编辑态改正文 → 保存 |
| 截图过时 | 编辑态点「🖼 插入截图」上传新图，删掉旧图；或直接替换 `uploads/manual/` 同名文件 |
| 新增功能模块 | 后台新建一节（选章、填标题），或用迁移脚本重跑（不影响已编辑的节） |
| 章节顺序调整 | 目录里拖/重排，走 `reorder` 接口 |

**唯一需要人工兜底的**：截图内容本身——系统改版后，涉及新旧界面的截图需要人工重拍替换；后台只能改文字和换图，不能自动生成截图。
