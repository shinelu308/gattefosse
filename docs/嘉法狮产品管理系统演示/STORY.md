## 意图对齐
- **受众**：管理层汇报 + 新手用户培训（小白也能一眼看懂）
- **目标**：让听众理解系统价值（1:1 复刻官网 + 后台集中管理）、知道自己用什么角色登录、三步上手
- **场合**：系统演示会 / 内部培训
- **调性**：品牌绿现代商务，与后台 UI / 功能架构图视觉一致
- **页数**：10 页
- **必讲**：系统定位与数据规模、功能架构图（嵌入 architecture.png）、三类角色、三步上手、核心功能演示要点、安全与部署
