# DESIGN.md — 嘉法狮产品管理系统演示

## 画布与母版（A/B/C 三区，全篇固定）
- 画布 1280×720，页面 padding：上 20 / 下 20 / 左 64 / 右 64
- **A 标题块**：0–120px，主标题 34px bold（#1F3D0F 深绿墨），右侧不放装饰小图
- **B 内容区**：120–660px（540px 可用），一切正文与图表
- **C 页脚条**：660–720px：左侧「嘉法狮产品管理系统」14px #8A9B7A，右侧页码 `NN / 10` 14px

## 色彩池（≤4 hex）
| 角色 | hex | 用途 / 面积 |
| :-- | :-- | :-- |
| 主色 | `#8EB73C` 品牌绿 | 标题条、大色块、图标主色，≤60%（hero 页可到 60%） |
| 辅色 | `#F4F9EA` 浅绿底 | 卡片背景、分区底色，≤30% |
| 强调色 | `#3F7D14` 深绿 | 巨型数字、CTA、焦点标注，≤10%（supporting ≤5%） |
| 中性 | `#1F3D0F` / `#5B6B4F` / `#FFFFFF` | 文本、页脚、卡片白底 |
- 渐变方案：`linear-gradient(135deg, #A5CE55 0%, #6F9A24 100%)`，仅用于封面横幅与结束页大色块
- 半透明：卡片头 `rgba(142,183,60,0.12)`；浅绿分隔条 `rgba(142,183,60,0.35)`
