嘉法狮 Gattefossé 网站管理系统

使用手册 · 面向内容编辑与运营同事
后台地址　https://gattefosse.loudaren.com/admin/　　前台地址　https://gattefosse.loudaren.com/
建议浏览器　Chrome / Edge 最新版（其它浏览器可能出现显示异常）

0开始之前

这个系统分两块：前台是访客看到的官网；后台是你们编辑内容的地方。后台改完并「保存」，前台刷新就能看到。 本手册按后台左侧菜单顺序编写，遇到不会的地方，直接翻到对应章节即可。
你会用到用途
后台 · 内容管理发文章、发活动、上传资料、改页面文案
后台 · 产品管理维护成分、配方、药用辅料
后台 · 运营看订单、管会员、管标签、配权限
前台检查改完的效果是否正常

13 分钟快速上手

先跑通一遍「登录 → 找到内容 → 改一处 → 看效果」，之后所有模块都是同一套逻辑。

  1. 浏览器打开后台地址，输入邮箱 + 密码，点「登录」。
  2. 左侧菜单点「内容管理 → 新闻与活动」，右侧出现列表。
  3. 在列表里找到一条内容，点它右侧的「编辑」。
  4. 改动标题或正文，拉到页面底部点「保存」。
  5. 打开前台对应页面，按 Ctrl+F5 强制刷新，确认改动已生效。
列表页、编辑页在所有模块长得都一样：列表页用来「找和筛」，编辑页用来「改和存」。学会一个模块，其它模块照搬即可。

2登录与账号

我想做的事怎么做
登录填邮箱和密码 → 登录。账号由管理员在「系统设置」里开通
退出点右上角「退出登录」
忘记密码联系系统管理员重置（后台不提供自助改密）
看不到某些菜单？那是权限没勾。请管理员到「系统设置 → 系统功能权限」给你的角色打勾，保存后重新登录生效。详见 7.5。

3总览看板

登录后的第一个页面，一眼看清网站访问情况。

四个数字怎么看

指标含义
今日访问量（PV）今天页面被打开了多少次（同一人多开几次也算多次）
今日访客数（UV）今天有多少个「不同的人」来访
昨日访问量昨天一共打开了多少次
累计访问量系统上线至今的总和
下方地图与「地区排行」显示访客来自哪些省市，可切换中国 / 世界，点「展开全部」看完整排行。

4内容热度

回答一个问题：哪个产品、哪份资料被看得最多？ 和总览不同，这里按「产品 / 资料 / 文章」这类业务对象统计，而不是按页面。

  1. 选时间范围（近 7 天 / 30 天 / 90 天 / 全部）。
  2. 选板块（全部 / 个人护理 …），只看某个产品线。
  3. 下方「未被浏览过的对象」列出从没被访问的产品与资料，适合安排推广。

5产品管理

左侧「产品管理」下有三块：个人护理（含「成分」「配方」两个子页）、药用辅料。三者页面结构一致。

列表页能做什么

  • 搜索：按产品名 / INCI 名称查找，回车或点搜索。
  • 筛选：点「展开筛选」，按功能分类、应用领域、状态等组合过滤。
  • 批量操作：勾选多行 →「批量删除」；或「导出 Excel」备份。
  • 上架 / 下架：控制这条内容在前台是否显示。

5.1 个人护理 · 成分

  1. 列表页点「+ 新增产品」（或某行的「编辑」）。
  2. 「基本信息」页填：产品名称*、INCI 名称*、宣传标语、产品描述。
  3. 传产品图片、详情大图（点「选择文件」上传，或粘贴图片 URL）。
  4. 有视频就填产品视频（B 站链接 / iframe 代码）与视频标题。
  5. 切到「标签与分类」页，勾选功能、应用领域、认证等标签。
  6. 底部点「保存」。想前台看得见，确认状态为「已发布」。
带 * 的是必填项；空着保存会提示。图片建议用清晰大图，前台会自适应缩放。

5.2 个人护理 · 配方

配方用于「配方查找器」。字段与成分类似，另有 编号、应用领域、剂型、天然指数。编辑步骤同 5.1。

5.3 药用辅料

结构同样是「列表 + 编辑」，搜索、筛选、上下架、批量删除都一样操作。

6内容管理

6.1 新闻与活动

  • 类型分「新闻」和「活动」，可在筛选区切换。
  • 新增/编辑时可填标题、摘要、正文、配图、发布日期。
  • 「从原站导入」用于一次性把 gattefosse.com 的对应文章抓过来（导入后仍需人工校对）。

6.2 获取灵感（文章 / 在线研讨会 / 出版物 / 杂志）

「获取灵感」是一个带 4 个标签页的合集，点顶部标签切换类型，列表与操作完全一致。

标签页用途
文章技术/趋势类图文，出现在「获取灵感 → 文章」
在线研讨会视频研讨回放，可填视频链接、是否需登录
出版物论文、会议报告等，含作者/出处/日期
杂志addiactive 系列，逐期维护（含 PDF、是否需登录）
Slug/URL 是这篇文章的网址后缀，留空会自动生成；一旦发布，不建议再改，否则旧链接会失效。

6.3 了解更多（5 个子页）

「了解更多」是给药用辅料客户看的资料区，含 5 个标签页：热点话题、在线研讨会、出版物、资料手册、Journées Galéniques。

点左侧菜单「了解更多」的任一子项，都会进到这个页面并自动切到对应标签页。

6.4 文档资源

全局的文件仓库：产品手册、配方资料、技术数据表、安全数据表都在这里，供产品详情页的「文件下载」区引用。

  • 筛选「公开 / 需登录」：需登录的文件，前台访客登录后才能下载。
  • 「类型」区分产品手册、配方资料、技术数据表、安全数据表等。

6.5 站点内容

管理首页、个人护理、药用辅料等独立页面的文案与区块，以及「寻找我们」页面的分公司/经销商信息。

这一页保存后，前台对应页面的文案才会更新。

6.6 作者管理

维护文章作者（姓名、职位、简介、头像、部门、地区），写文章时可直接选择。

  • 头像有两种填法：直接贴图片网址，或点「本地上传」选电脑里的图片（限图片格式、≤5MB）。
  • 列表里头像按 44×44 圆形显示并自动裁切，建议用正方形图（如 400×400），长方形会被裁掉两边。
  • 头像留空不影响使用——只是列表这一格空着，不会报错。
  • 「排序」在编辑弹窗里填数字，数字越小越靠前；它只影响后台列表顺序。

7运营

7.1 样品订单

  1. 用「状态」筛出待处理的申请。
  2. 点「详情」查看客户公司、联系人、申请的样品清单。
  3. 线下跟进后，回到列表更新状态。

7.2 用户管理（前台会员）

  • 这里管的是前台注册的客户会员：审核、禁用、删除。
  • 公司员工与系统操作人员不在这里，请在「系统设置 → 企业组织架构」中管理（见 7.5）。

7.3 招聘管理

7.4 标签管理

维护前台筛选器里的标签（功能、应用领域、认证…）。改标签会影响前台筛选结果，务必谨慎。

  1. 顶部两个下拉：选产品线（成分/配方/药用辅料…）与分类（功能/应用领域…）。
  2. 表格里可「编辑」改名或排序、「删除」移除标签。
  3. 底部点「开始检查」，系统会列出：产品用了但字典没有的标签、字典有却没人用的「死标签」、同值冲突等。
删标签前先确认没有产品在用；改名/删除都会影响前台筛选。

7.5 系统设置 · 员工与权限

「系统设置」共 5 个标签页：企业基本信息、企业组织架构、系统功能权限、AI 翻译配置、邮件通知。

① 企业基本信息

② 企业组织架构（管员工账号）

  • 部门：点「+ 添加部门」建部门，填名称、负责人、排序；员工按「所属部门」自动归组。
  • 员工账号：点「+ 新增员工」开通登录账号；忘记密码时点「重置密码」。
  • 「超级管理员」为系统内置账号，不可编辑/禁用/删除。

③ 系统功能权限（勾菜单权限）

  1. 找到要授权的功能模块（每一行就是后台左侧的一个菜单）。
  2. 在对应角色列（如「编辑员」）里打勾。
  3. 点「保存设置」。
  4. 让该同事退出后重新登录——权限在重新登录后才生效。
如果同事反映「勾了权限但还是看不到菜单」，通常是没重新登录。另注意：未勾选的模块，其所有子页也会一并隐藏。
