嘉法狮网站 · 上线部署手册

不需要懂技术，按顺序点、按顺序填，就能把你现在电脑上的网站搬到腾讯云上，让全国人都能访问
预计耗时：备案等待 7–20 天（纯等待）+ 动手操作约 1 小时

零、先弄懂 5 个词（30 秒，后面全靠它们）

名词大白话是什么
服务器腾讯云上租的一台「永远不关机的电脑」。你的网站文件就放在这台电脑里，24 小时运行
域名网站的门牌号，比如 www.gattefossechina.cn。别人在浏览器输入它就能找到你的网站
备案相当于「营业执照」。中国大陆的服务器，域名没有备案就无法对外访问，这是硬性规定
Nginx前台接待员。访客敲的是 80 号门（网页默认门），Nginx 负责把人带到 3000 号房间（你的程序）
PM2保姆。程序万一崩溃了自动拉起来，服务器重启后也自动启动，不用你管
💡 你的网站结构很简单：前台网页 + 后台管理 + 接口程序，全部由同一个 Node 程序提供（端口 3000），数据库是一个文件（SQLite）。所以服务器上不需要装 MySQL，这一步省了很多麻烦。

二、8 步操作（每步都有「怎么算成功」）

1买服务器 + 选镜像
  1. 打开 腾讯云官网 → 轻量应用服务器 → 新建实例
  2. 地域：选「上海」或「北京」；镜像：应用镜像 → 宝塔面板（强烈推荐，图形界面，不用敲命令）
  3. 套餐：2 核 4G / 60G SSD / 5 Mbps；购买时长选 1 年起（更便宜）
  4. 付款后，在实例列表里能看到你的服务器和公网 IP（一串数字，如 129.204.x.x），把这个 IP 记下来
✅ 怎么算成功：实例状态显示「运行中」，能看到公网 IP。
2放行端口（防火墙）
  1. 控制台 → 点击你的实例 → 防火墙 → 添加规则
  2. 依次添加 4 条，应用类型选「自定义」：
端口用途来源
22远程登录（SSH）全部 IPv4
80网页访问（http）全部 IPv4
443加密网页（https）全部 IPv4
8888宝塔面板全部 IPv4
✅ 怎么算成功：浏览器输入 http://你的公网IP:8888 能打开宝塔登录页。
3登录宝塔，安装运行环境
  1. 进入宝塔面板（首次登录会让你绑定手机号，按提示来）
  2. 首次登录会弹窗推荐安装套件 → 勾选 Nginx，其他可先不装，点「一键安装」
  3. 装完后，左侧点 软件商店 → 搜索 「Node.js 版本管理器」 → 安装
  4. 打开 Node.js 版本管理器 → 版本选 Node 20 → 安装；再点「命令行版本」设置为 20
  5. 回到宝塔「终端」（左侧菜单），输入以下命令安装 PM2 并回车（耐心等 1 分钟）：
    npm install -g pm2 --registry=https://registry.npmmirror.com
✅ 怎么算成功：终端里输入 node -v 显示 v20.x，输入 pm2 -v 显示版本号。
4把网站文件搬到服务器

在你自己电脑上先打包（不要包含 node_modules，太大）：

  • 把整个 嘉法狮网站重建 文件夹压缩成 gattefosse.zip
    （如果压缩包超过 700MB，主要是 site 里的 PDF 资料，可以先把 site 里的 *.pdf 暂时移走，上线后再单独传）

然后上传到服务器：

  1. 宝塔左侧 → 文件 → 进入 /www/wwwroot → 点「上传」，选择刚才的 zip
  2. 上传完，右键 zip → 解压 → 解压到 /www/wwwroot/gattefosse
⚠️ 解压后请确认目录结构是这个样子：
/www/wwwroot/gattefosse/
├── backend/     （后端程序）
│   ├── dist/    （编译后代码，本地已生成）
│   └── prisma/gattefosse.db   ← 数据库，你的全部数据在这
├── site/        （前台网页）
├── admin/       （后台管理页）
├── uploads/     （上传的图片/PDF）
└── deploy/      （我给你准备好的配置文件）
✅ 怎么算成功：宝塔文件管理里能看到 /www/wwwroot/gattefosse/backend/dist/index.js 这个文件。
5改 3 处配置（我已经准备好模板）
  1. 宝塔文件管理，进入 /www/wwwroot/gattefosse/backend/
  2. 找到我准备好的 deploy/.env.production.example，复制一份，命名为 .env，放在 backend/ 目录下
  3. 双击编辑 .env，只改 3 处（其他保持原样）：
要改的项改成什么
JWT_SECRET换成一串随机字符（乱打 30 个字母数字都行）。这是登录令牌的钥匙，不换有安全风险
FRONTEND_URLhttps://www.你的域名.com
BASE_URLhttps://www.你的域名.com
🔒 安全提醒：JWT_SECRET 一定要改。它相当于网站后台登录的万能钥匙，用默认值等于把钥匙放在门口。
6启动网站程序
  1. 宝塔左侧 → 终端，粘贴下面命令回车（首次约 2–5 分钟）：
    cd /www/wwwroot/gattefosse && bash deploy/deploy.sh
  2. 这个脚本会自动帮你：装依赖 → 生成数据库客户端 → 编译 → 用 PM2 启动并设置开机自启
  3. 看到「部署完成」就是成功了
✅ 怎么算成功：终端输入 curl http://127.0.0.1:3000/api/health，返回 {"status":"ok"...}。
再输入 pm2 status，能看到 gattefosse 状态是 online。
如果状态码不是 online，输入 pm2 logs gattefosse 看报错，把报错内容发给我，我帮你看。
7把域名指向服务器
  1. 打开你的域名管理后台（腾讯云 → 域名管理 → 解析）
  2. 添加两条记录：
主机记录记录类型记录值
wwwA你的服务器公网 IP
@A你的服务器公网 IP
✅ 怎么算成功：等 5 分钟后，在你电脑上打开「命令提示符」，输入 ping www.你的域名.com，显示的 IP 是你的服务器 IP 就对了。
8配置网站入口 + 申请 HTTPS 小绿锁

A. 添加站点（宝塔 → 网站 → 添加站点）：

  • 域名：填 www.你的域名.com 和 你的域名.com（两个都填）
  • 根目录：/www/wwwroot/gattefosse/site
  • 数据库、PHP：都不选（我们用不上）

B. 设置反向代理（关键一步，让 80 门通向 3000 房间）：

  1. 网站列表 → 点你刚建的站点「设置」→ 反向代理 → 添加反向代理
  2. 代理名称：gattefosse；目标 URL：http://127.0.0.1:3000；其他默认 → 提交

C. 申请 HTTPS 证书（小绿锁）：

  1. 站点设置 → SSL → Let's Encrypt → 选「文件验证」→ 申请
  2. 申请成功后打开「强制 HTTPS」开关
✅ 怎么算成功：浏览器打开 https://www.你的域名.com 能看到网站首页；打开 https://www.你的域名.com/admin 能看到后台登录页。

三、上线验收清单（逐条打勾）

  • 打开 https://你的域名.com → 前台首页正常显示，图片能加载
  • 打开 https://你的域名.com/admin → 后台登录页，用超管账号能登录进去
  • 后台「总览」→ 能看到访问统计地图和数据
  • 随便点开一个产品页 → 图片、PDF 下载链接都正常
  • 前台注册一个新会员 → 后台「用户管理」里能看到（验证数据库写入正常）
  • 地址栏左侧是小绿锁（HTTPS 生效）

四、以后怎么更新网站（改了代码后）

在你自己电脑上改完代码、测试没问题后：

  1. 本地执行 cd backend && npx tsc 重新编译
  2. 把改动的文件（或整个目录重新打包）上传到服务器覆盖
  3. 宝塔终端执行：cd /www/wwwroot/gattefosse && bash deploy/deploy.sh
  4. 刷新网页即可（前台页面记得 Ctrl+F5 强刷）

数据不会丢——所有内容都存在 backend/prisma/gattefosse.db 这一个文件里，更新代码不会动它。

五、新手最容易踩的 5 个坑

坑怎么避开
域名没备案网站一定打不开。这是硬性规定，先备案再谈其他
忘了放行 80/443 端口症状是「服务器能 ping 通但网页打不开」。先查防火墙
上传时丢了数据库文件一定要确认 backend/prisma/gattefosse.db 一起传上去了，否则是空网站
上传的文件打不开给 backend/uploads 目录设置权限 755（宝塔文件管理右键 → 权限）
JWT_SECRET 没改任何人都能伪造登录令牌，务必换成随机字符串

六、上线后要做的 2 件保命事

1. 开自动快照（服务器整机备份）

腾讯云控制台 → 轻量服务器 → 快照 → 设置自动快照策略（每天一次，保留 7 天）。
收费很少，出问题时能一键把服务器恢复到昨天。

2. 定期下载数据库文件

宝塔文件管理 → 进入 /www/wwwroot/gattefosse/backend/prisma/ → 右键 gattefosse.db → 下载。
建议每周下载一次存到自己电脑——这是你网站全部内容的唯一副本，1.4MB 很小，比什么都重要。
